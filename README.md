# 🎧 MixxxDroid

**MixxxDroid** es una aplicación de DJ para Android diseñada para reproducir y mezclar música desde dispositivos móviles.

El proyecto busca ofrecer una experiencia de mezcla musical con controles intuitivos, procesamiento de audio y herramientas propias de una mesa de DJ.

> 🚧 **Estado del proyecto: En desarrollo**

## ✨ Funcionalidades

- 🎵 Reproducción de audio en dos decks.
- 🔊 Control de volumen.
- 🔁 Función Loop.
- 🎯 CUE y Hot Cue.
- 🎚️ Control de tempo (Pitch).
- ↩️ Restablecimiento del tempo.
- 🎛️ Scratch (desarrollo parcial).
- 🤖 AutoMix (en desarrollo).

Algunas funcionalidades todavía están pendientes de implementación o mejora.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Kotlin.
- **Interfaz:** Jetpack Compose.
- **Plataforma:** Android.
- **Procesamiento de audio:** MediaCodec y AudioTrack.
- **Código nativo:** C++ mediante JNI.
- **Procesamiento de tempo:** SoundTouch.
- **Motor de audio:** componentes nativos para reproducción y procesamiento.

## 📱 Requisitos

- Android 9.0 (API 28) o superior.
- Dispositivo Android compatible.
- Espacio de almacenamiento para los archivos musicales.
